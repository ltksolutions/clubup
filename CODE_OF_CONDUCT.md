# Code of Conduct

Tento projekt vytvára otvorenú a vítanú komunitu. Od všetkých prispievateľov, autorov, údržbárov a uchádzačov o pomoc očakávame nasledovné správanie:

## Naše záväzky

- Vytvárame priateľské a podporné prostredie bez ohľadu na vek, pohlavie, rod, sexuálnu orientáciu, postihnutie, vzhľad, telesnú stavbu, etnicitu, národnosť, náboženstvo, technickú zdatnosť alebo skúsenosti
- Komunikujeme úctivo a vecne
- Vítame konštruktívnu kritiku a vieme ju aj poskytnúť
- Sústreďujeme sa na to, čo je najlepšie pre projekt a komunitu
- Prejavujeme empatiu k ostatným členom

## Neakceptovateľné správanie

- Sexualizovaný jazyk, obrázky alebo nevyžiadaná pozornosť
- Trolling, urážlivé komentáre a osobné/politické útoky
- Verejné alebo súkromné obťažovanie
- Zverejňovanie cudzích súkromných informácií bez výslovného povolenia
- Iné správanie, ktoré by mohlo byť racionálne považované za nevhodné v profesionálnom prostredí

## Vymáhanie

Prípady neakceptovateľného správania nahláste na **info@clubup.sk**. Všetky sťažnosti budú preskúmané a vyšetrené, výsledok bude komunikovaný iniciátorovi.

Maintaineri majú právo a zodpovednosť odstrániť, upraviť alebo odmietnuť komentáre, commity, kód, úpravy wiki, issues alebo iné príspevky, ktoré nie sú v súlade s týmto Code of Conduct.

## Atribúcia

Tento Code of Conduct je adaptovaný z [Contributor Covenant](https://www.contributor-covenant.org), verzia 2.1.
